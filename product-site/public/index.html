Terminal · from source
git clone https://github.com/haichangcharles/dsh-context-map.git
cd dsh-context-map
pnpm install
pnpm run build
pnpm dsh web

Requires Node.js ^22.19 or ≥24 and pnpm. Configure your model provider in the local app.

Upgrading an older Context Map installation? Keep existing session data on the previous runtime until a compatible migration is available. Read upgrade notes ↗
