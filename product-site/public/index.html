01 / Branch from Here

Explore a new direction.
Keep the starting point.

When one answer opens another possibility, branch from that exact message. The original conversation stays in place, and the new session shares its history up to that point.

Right-click a message → Branch from Here.
02 / Cross-branch context

Use the best parts.
Leave the detours out.

Working in the enterprise branch, but want to reuse the community launch answer? Include that message from the other branch and exclude the sales-led answer. Your next request uses the selection; original messages remain in their sessions.

Check Context to include a message. Uncheck it to exclude.
03 / Fast / Deep Review

Inspect the suggestion.
Apply it when you’re ready.

Use Fast Review for a bounded check or Deep Review for a complete-tree inspection. Read the proposed changes and their reasons before applying them. Undo or redo a context revision when you want to reconsider.

Recommend → review changes → Apply. Undo is available afterward.
04 / Archive & Restore

Archive the old content.
Keep its place in the map.

When a message is obsolete, Archive replaces its context content with a placeholder. The node, its connections and the original event remain. Show original to inspect it, or Restore node to bring it back.

Archive node → Show original / Restore node.
05 / Prompt Dashboard

Give reviewers
your own rules.

Add instructions for Context, Archive and Branch reviewers while keeping the default prompts visible. Advanced users can explicitly unlock a full override. Optional Automatic Branch review can suggest moving a completed exchange into a parallel session; it is off by default.

Settings → Context Map prompts.
