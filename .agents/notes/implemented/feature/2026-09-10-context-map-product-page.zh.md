# Agent Note: Context Map 产品首页

Status: implemented

[English](2026-09-10-context-map-product-page.md) | 中文

## 问题

Fork 的 GitHub Pages 首页展示上游文档，而非 Context Map 产品。访客需要简洁介绍、可体验的上下文选择交互和源码安装入口。

## 决策

产品首页的静态 HTML、CSS 和浏览器 JavaScript 位于 `product-site/public`。暗色版式参考 Linear 与 Zed，采用近黑中性背景、清晰文字、低对比边框和克制的绿色点缀，文案和示例界面独立制作。默认英文；由 URL 保存的中文切换保留演示选择。示例图和分支控件仅操作本地示例数据，并明确标记为示例，不发起模型请求或修改真实 Session。

构建将产品首页覆盖到文档产物中，保留文档路由。Fork 专用 Pages 工作流从 master 发布组合产物。上游手动文档工作流不在本 fork 部署，防止后续文档发布覆盖产品首页。两个工作流保留相同的 Pages 并发组。

## 考虑的替代方案

用独立落地页部署替换文档会破坏已有指南地址。将宣传页放入 Agent Web 应用会让公开静态介绍依赖私有会话与运行时设施。复制其他品牌的素材或宣传主张会误导访客对本社区项目的理解。

## 后果

首页无需凭据或运行时即可由 GitHub Pages 托管。源码安装及旧会话迁移限制保持可见。发布仍然构建文档，并使用已有 Pages 环境策略，不移除保护。

## 验证

验证桌面和移动端布局、双语文案、节点选择与重置、分支切换、剪贴板行为和控制台错误。先构建文档再覆盖首页，确认文档路由保留，随后确认线上首页使用 DSH Context Map 品牌。演示仅说明交互方式，不代表真实 Agent 运行。
